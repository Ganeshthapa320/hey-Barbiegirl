IMPORTANT PRIVACY NOTES
- A private GitHub repository protects the source repository, not a public deployed website.
- Noindex/robots.txt makes the site less discoverable; it does NOT make the URL private or prevent access by someone who has the link.
- The on-page PIN is a casual privacy gate only. It is stored in the page's JavaScript and is not strong security.
- For genuine protection on Netlify, use the hosting provider's server-side access controls. On current credit-based Netlify Free/Personal plans, shared-password visibility is not available; Password visibility is Pro-only. A Private project restricts access to the Netlify team owner on Free/Personal.
- Do not upload private photos or other sensitive files to a public deployment unless server-side protection is enabled.
